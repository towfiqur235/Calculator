# 🧮 Calculator

A simple and responsive **Calculator Web Application** built using **HTML, CSS, and JavaScript**. This project provides a clean calculator interface with basic arithmetic operations and an easy-to-use design.

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* % Percentage
* 🔄 **AC** – Clear the complete input
* ⌫ **DEL** – Delete the last entered character
* 🔢 Decimal number support
* 🔢 Double-zero (`00`) button
* 🎨 Modern dark-themed user interface
* 📱 Responsive and simple layout
* ⚡ Instant calculation using JavaScript

## 🛠️ Technologies Used

* **HTML5** – For creating the calculator structure
* **CSS3** – For styling, layout, gradient background, buttons, and calculator UI
* **JavaScript** – For handling button clicks and performing calculations

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Run the file using a browser or **Live Server**.
5. Start using the calculator.

## 🧠 How It Works

The calculator uses JavaScript to detect which button the user clicks and stores the entered values in a string.

* `AC` clears the entire calculation.
* `DEL` removes the last entered character.
* `=` evaluates the entered mathematical expression.
* Number and operator buttons are added to the input field dynamically.

JavaScript event listeners are used to handle all calculator button interactions.
